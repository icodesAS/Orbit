# Orbit UI (replaces the dark design in 02_DESIGN_SYSTEM)
Feel: calm project tracker. Like Google Calendar / Linear light.
Colors: page #F5F5F3, cards #FFFFFF, lines #E5E5E1, text #16181D,
  muted #6B7280, accent indigo #4355B9 (buttons, links, focus only),
  amber #B54708 on #FEF0C7, red #D92D20 on #FEE4E2, green #067647.
Type: Inter 14px for text. JetBrains Mono only for dates, numbers, IDs.
  One touch of italic serif (e.g. EB Garamond) in the page heading only.
Shape: 8px corners, 1px lines, no shadows except popups.
Sidebar: labelled (icon + text), 220px, collapsible.
Home = Today: "Due soon" list, then a link "6 new in this morning's digest".
Pipeline: clean table rows grouped by the three tiers.
Radar: one dated digest page. Headings 1A, 1B, 1C, 2. One line per
  item: name, deadline, fits (PatchTree / SentinelFlow / Fresh),
  source link, small Track button. Date switcher at the top.
Deadline chips: soft tinted background, no pulsing glow. The red
  chip may have one small static dot.
Motion: 150-200ms fades only. Respect reduced motion.
Empty states: one plain sentence and one button.
